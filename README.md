# 말하기 짝꿍 v3

낱말과 문장을 듣고 따라 말하며 매일 조금씩 연습하는 한글 발음 연습 웹앱입니다. 치료나 진단을 대신하지 않는 연습 도구입니다.

- 배포: **GitHub → Vercel** (자세한 순서는 [배포안내.md](./배포안내.md))
- 화면: `public/` (빌드 없음, 순수 HTML·CSS·JS, 외부 라이브러리 없음)
- 백업 서버: `api/vault.js` (Vercel Function, Upstash Redis REST, 추가 패키지 없음)

## 기능

- 오늘의 낱말 10개·문장 5개 (날짜마다 바뀜, 같은 날은 같은 목록)
- 분야별 낱말(12분야)·문장(8상황), 나만의 낱말·문장
- 연습: 자동으로 한 번 들려주기, 다시 듣기, 천천히 듣기, 이전·다음, 들은 횟수
- 어제 연습 다시 하기, 달력에서 지난 날짜 골라 다시 하기
- 글씨 크기 5단계, 목소리·빠르기 고르기, 전체화면(안 되는 기기는 홈 화면 추가 안내)
- 오프라인 연습 (서비스 워커)
- 기록 백업(선택): 기기에서 AES-GCM으로 암호화 → 서버에는 암호문만. 복구 코드 16자리로 다른 기기에서 불러오기
- 기록 파일 내려받기·불러오기 (백업 서버 없이도 기기 옮기기)

## 백업 구조

```
복구 코드(16자, 80비트) ─PBKDF2-SHA256(210,000회)→ 512비트
   ├─ 앞 256비트: AES-GCM 열쇠 (기기 밖으로 안 나감)
   └─ 뒤 256비트: 열쇠 확인값 → 서버는 SHA-256 해시만 보관
백업 번호 = SHA-256("vault-id|" + 확인값) 앞 128비트
```

- `GET /api/vault?ping=1` 상태 · `GET` 가져오기 · `PUT {n, d}` 저장(판 번호가 다르면 409) · `DELETE` 지우기
- 같은 접속 주소 1분 60회, 같은 백업 인증 실패 1시간 10회 제한. 마지막 사용 400일 뒤 자동 삭제
- 여러 기기 합치기: 들은 횟수는 큰 쪽, 항목은 모두, 나만의 낱말은 나중에 바뀐 쪽

## 시험

```bash
node --test tests/*.test.js                 # 서버·암호화·합치기·목록 (20개)
node tests/dev-server.js 8787 &             # 가짜 Redis로 앱+서버 띄우기
NO_BACKUP=1 node tests/dev-server.js 8788 & # 백업 서버 없는 상태
python3 tests/e2e.py                        # Chrome으로 처음부터 끝까지 (36개)
```
